# 推送前敏感字串攔截清單 —— 範例檔
#
# 用法：
#   cp _sensitive-patterns.example.txt _sensitive-patterns.txt
#   然後把下方樣式換成「你自己專案」真正要攔截的詞。
#
# 格式：每行一條 grep -E（POSIX 擴充正則）樣式。
#      空行、以及 # 開頭的行會被忽略。
#
# ⚠ 為什麼要分成兩個檔
#   這份清單本身就會列出要保護的名字。若它入庫（尤其 public repo），
#   等於把想保護的客戶／專案／人名直接公開 —— 閘門反而變成洩漏源。
#   所以：真清單放 _sensitive-patterns.txt，該檔已列入 .gitignore。
#   本範例檔只放佔位字，可以安全入庫。
#
# ⚠ 找不到 _sensitive-patterns.txt 時，push-to-github.sh 會直接中止推送
#   （fail closed：寧可不推，也不要無閘門地推）。
# ============================================================================
